1. What is SOQL?
SOQL means Salesforce Object Query Language.
It is used to get data from Salesforce objects.
It works similar to SQL.
We can use SOQL to read records like Account, Contact and Opportunity.
Example:
SQL
SELECT Name FROM Account

3. What is an Apex Trigger?
An Apex Trigger is a code which runs automatically when records are created, updated or deleted in Salesforce.
Triggers are used to automate tasks and apply business logic.
