What is Flow Builder?
Flow Builder is a Salesforce tool used to create automation without coding. It helps in automating tasks like updating records, sending notifications, and creating workflows using drag and drop.

Types of Flows
Screen Flow
Screen Flow is used to collect input from users through screens. It is mainly used for forms and step-by-step processes.
Record Triggered Flow
Record Triggered Flow runs automatically when a record is created or updated. It helps in automating actions like sending alerts and updating related records.
