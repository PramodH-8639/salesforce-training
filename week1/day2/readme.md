1. What is Salesforce Platform?
Salesforce Platform is a cloud-based platform used to build business applications and manage customer data. It helps companies store information, automate tasks, create apps, and improve business processes. Salesforce provides many tools that allow both developers and non-developers to create applications easily. Since it is cloud-based, users can access it from anywhere using the internet without installing heavy software.

2. Explain App, Object, and Tab
An app in Salesforce is a collection of tabs, tools, and features that are grouped together for a specific purpose. For example, a sales app can contain accounts, contacts, leads, and reports. An object is used to store data in Salesforce and it works like a table in a database. Objects contain records and fields to organize information. A tab is used to open and access objects, reports, dashboards, or other features inside Salesforce quickly through the user interface.

3. Difference Between Configuration and Coding
Configuration means customizing Salesforce using settings, clicks, drag-and-drop tools, flows, and automation without writing programming code. It is mainly used for simple business requirements and faster development. Coding means writing programs using technologies like Apex and Lightning Web Components to create advanced features and custom logic. Configuration is easier and faster, while coding is useful for complex requirements.

4. Your System Design
My system design is based on a simple Property Management application. The app contains objects like Properties, Brokers, and Customers. The Properties object stores information about houses or buildings, the Brokers object stores broker details, and the Customers object stores customer information. Users can add new properties, view property details, manage brokers, and interact with customer records. The application helps organize property-related information in a structured and user-friendly way.
